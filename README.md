# Project Overview

Fork & Flame is a restaurant review web application built using Flask, SQLite, HTML, CSS, and JavaScript.

The platform allows users to:
- Browse restaurants
- Read customer reviews
- Register and log in
- Access customer dashboards
- Manage authentication sessions

The frontend is served through Flask routes instead of opening HTML files directly.

---

- HTML/CSS/JavaScript
- Bootstrap 5
